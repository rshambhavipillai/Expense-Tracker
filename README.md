# Spendly

A small, dependency-free expense tracker that runs directly in the browser.

## Run locally

Open `index.html` in a browser. Expenses are saved in the browser's local storage, so they remain available when the page is reopened on the same device and browser.

## Included

- Expense entry form with description, euro amount, date, and category
- Total spending and expense count summary
- Recent expenses list with remove and clear-all actions
- Responsive layout for desktop and mobile
